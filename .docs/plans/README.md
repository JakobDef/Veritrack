# Plans

Implementation plans, one file per task, written by the `planner` agent before code is touched. Filename format: `YYYY-MM-DD-<short-slug>.md`. Each plan carries `status`/`created`/`updated`/`base`/`goal` frontmatter and a milestone body of `- [ ]` checkboxes that the implementer ticks live. See `.docs/rules/plan-execution.md` for the mandatory format and the resume protocol.
