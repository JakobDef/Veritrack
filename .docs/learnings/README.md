# Learnings

Append-only lessons distilled from past sessions by the `learner` agent (or via `/learn`). Filename format: `YYYY-MM-DD-<short-slug>.md`, with required frontmatter: `date`, `tags`, `severity`, `applies-to`. Only write a learning if it would change behavior next time; most sessions produce none. Never delete a learning: supersede it by adding a `superseded-by:` line to its frontmatter.
